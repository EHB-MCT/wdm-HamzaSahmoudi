# Code of Conduct

## Our Pledge

We are committed to making participation in this project a harassment-free experience for everyone, regardless of level of experience, gender, gender identity and expression, sexual orientation, disability, personal appearance, body size, race, ethnicity, age, religion, or nationality.

## Our Standards

### Expected Behavior

- Use respectful and inclusive language in all interactions
- Be considerate of different viewpoints and experiences
- Focus on what is best for the community and the project
- Show empathy towards other community members
- Be respectful when providing constructive feedback
- Accept feedback gracefully and work towards improving the project
- Help maintain a welcoming environment for all contributors
- Follow established coding standards and documentation practices

### Unacceptable Behavior

- The use of sexualized language or imagery, and unwelcome sexual attention or advances
- Trolling, insulting or derogatory comments, and personal or political attacks
- Public or private harassment
- Publishing others' private information, such as a physical or electronic address, without explicit permission
- Any conduct which could reasonably be considered inappropriate in a professional setting
- Intentionally disrupting discussions or project workflows
- Spreading misinformation or making false claims about the project or contributors
- Plagiarism or failure to properly cite sources and AI assistance

## Academic Integrity

As this is an academic project, we expect all contributors to maintain the highest standards of academic integrity:

- Properly cite all sources, including code snippets, documentation, and research materials
- Document any use of AI tools or assistance in your work
- Avoid plagiarism of code, documentation, or any project materials
- Give credit to original authors and contributors appropriately

## Scope

This Code of Conduct applies to all spaces managed by the Games Tracker project, including but not limited to:

- GitHub repositories (issues, pull requests, discussions)
- Project documentation and code reviews
- Any communication channels related to the project
- In-person meetings or online calls related to the project

The Code of Conduct also applies when an individual is representing the project or its community in public spaces.

## Reporting

## Enforcement

### Consequences

Violations of this Code of Conduct may result in:

1. **Warning** - A private message explaining the violation and requesting that the behavior stop
2. **Temporary Restriction** - Temporary removal from project spaces (e.g., temporary ban from discussions, PR reviews)
3. **Removal** - Permanent removal from project spaces and restriction from future participation

The project team will determine the appropriate response based on the severity and nature of the violation. All decisions will be made with consideration for maintaining a safe and inclusive environment for all participants.
